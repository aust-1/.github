# .github

This repository holds the default community health files for [aust-1](https://github.com/aust-1)'s repositories, as well as the GitHub profile README.

GitHub automatically applies these files to every repository of the account that does not provide its own version.

## Contents

| File | Purpose |
| ---- | ------- |
| [`CONTRIBUTING.md`](./CONTRIBUTING.md) | Contribution guidelines (code style, documentation, testing, Conventional Commits, GitFlow branching) |
| [`CODE_OF_CONDUCT.md`](./CODE_OF_CONDUCT.md) | Code of conduct for all interactions |
| [`SECURITY.md`](./SECURITY.md) | Security policy and how to report a vulnerability |
| [`SUPPORT.md`](./SUPPORT.md) | Support guidelines and how to open an issue |
| [`ACKNOWLEDGMENTS.md`](./ACKNOWLEDGMENTS.md) | Template to credit contributors and used projects |
| [`ISSUE_TEMPLATE/`](./ISSUE_TEMPLATE) | Issue forms: bug report, feature request, question or support request |
| [`PULL_REQUEST_TEMPLATE.md`](./PULL_REQUEST_TEMPLATE.md) | Default pull request template |
| [`RELEASE_TEMPLATE.md`](./RELEASE_TEMPLATE.md) | Template for release notes |
| [`profile/README.md`](./profile/README.md) | Profile README displayed on [github.com/aust-1](https://github.com/aust-1) |

## Overriding the defaults

A repository can override any of these files by adding its own version at its root, in `docs/` or in `.github/`.
